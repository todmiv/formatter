# Форматировщик документов по ГОСТ (Audit & Apply)

Программное обеспечение для диагностики и контролируемого форматирования документов Microsoft Word (DOCX) в соответствии с требованиями ГОСТ Р 21.101-2020, ГОСТ 2.105-2019 и ГОСТ 7.32-2017.

## Основные возможности

- **Глубокий аудит** – полное сканирование документа без внесения изменений. Сравнение каждого свойства (шрифт, отступ, интервал) с эталоном из конфигурации.
- **Детализированный отчет** – список всех найденных проблем с указанием номера страницы, номера абзаца, типа нарушения, текущего и ожидаемого значений.
- **Интерактивное применение исправлений** – пользователь может выбрать, какие проблемы исправить (точечно или все сразу).
- **Безопасный режим** – исходный файл никогда не изменяется напрямую до явного подтверждения пользователем.
- **Визуальная подсветка** – создание копии документа с цветным выделением проблемных элементов.
- **Импорт из Markdown** – конвертация Markdown-файлов в DOCX с применением стилей по ГОСТ.
- **Инициализация стилей** – подготовка документа (создание стилей, настройка полей, колонтитулов) без изменения текста.
- **Гибкая конфигурация** – поддержка YAML-файлов конфигурации, настраиваемые допуски, правила определения стилей.
- **Универсальная система location** – точное определение местоположения элементов (параграфы, таблицы, ячейки, колонтитулы) для гарантированного исправления.
- **Поддержка таблиц** – аудит и применение стилей к таблицам, ячейкам, строкам с исправлением выравнивания, границ и отступов.
- **Обработка колонтитулов** – аудит и исправление header/footer в соответствии с конфигурацией, поддержка разных колонтитулов для четных/нечетных страниц.
- **Итеративное применение** – механизм повторного аудита и применения исправлений до достижения 100% соответствия ГОСТ.

## Архитектура

Проект построен по модульному принципу с разделением логики и интерфейса:

- **GUI (Tkinter)** – трёхпанельный интерфейс с деревом документа, таблицей проблем и панелью деталей.
- **MainController** – центральный контроллер, управляющий состоянием приложения (AUDIT → REVIEW → APPLY).
- **AuditEngine** – движок аудита, выполняющий сканирование документа и сравнение с конфигурацией.
- **ApplyOrchestrator** – координатор применения исправлений, делегирующий работу специализированным апплерам (FontApplier, ParagraphApplier, TableApplier, HeaderFooterApplier).
- **ReportManager** – менеджер отчётности, обеспечивающий фильтрацию, группировку и экспорт проблем.
- **ConfigLoader** – загрузчик и валидатор YAML-конфигурации.
- **StyleManager** – общий модуль управления стилями для ApplyOrchestrator и md_to_docx.
- **PageManager** – модуль настройки полей страницы, ориентации и колонтитулов.
- **DocumentModel** – обёртка над python-docx для удобной работы с документом.

### Пакет src/apply/
После рефакторинга модуль применения исправлений разделён на специализированные подмодули:

- **src/apply/base_applier.py** – базовый класс с общими методами (`_get_paragraph`, `_get_table`, `_get_element`, `clear_direct_formatting`)
- **src/apply/paragraph_applier.py** – ParagraphApplier для исправления параграфов
- **src/apply/table_applier.py** – TableApplier для работы с таблицами
- **src/apply/header_footer_applier.py** – HeaderFooterApplier для колонтитулов
- **src/apply/font_applier.py** – FontApplier для шрифтов
- **src/apply/apply_orchestrator.py** – ApplyOrchestrator, координирующий применение исправлений

Такая архитектура повышает модульность, упрощает поддержку и позволяет независимо развивать каждый компонент.

## Конфигурация

Конфигурация задаётся в YAML-файле (по умолчанию `configs/active/config.yaml`). Пример структуры:

```yaml
version: "4.2"
name: "НТД 01-2013 Редакция 4 (с таблицами)"
description: "Конфигурация на основе Рабочей Инструкции по оформлению проектной градостроительной документации"

styles:
  Normal:
    enabled: true
    font:
      name: "Times New Roman"
      size: 12
    paragraph:
      first_line_indent_cm: 1.25
      line_spacing: 1.15
      alignment: "justify"
  Heading 1:
    enabled: true
    font:
      name: "Times New Roman"
      size: 14
    paragraph:
      first_line_indent_cm: 0
      line_spacing: 1.25
      alignment: "left"
      page_break_before: true

detection_rules:
  Heading 1:
    - "РАЗДЕЛ "
    - "^РАЗДЕЛ\\s+\\d+"

page_setup:
  portrait:
    left_margin_cm: 2.5
    right_margin_cm: 1.0
    top_margin_cm: 2.0
    bottom_margin_cm: 2.0
  landscape:
    left_margin_cm: 2.0
    right_margin_cm: 2.0
    top_margin_cm: 2.5
    bottom_margin_cm: 1.0
  paper_size: "A4"
  orientation_default: "portrait"

headers_footers:
  header:
    enabled: true
    position_from_edge_cm: 1.0
    content: "page_number"
    alignment: "right"
  footer:
    enabled: true
    position_from_edge_cm: 1.0
    content: "section_chapter_number"
    alignment: "center"
```

Подробное описание всех параметров конфигурации см. в [документации](docs/user_guides/USER_GUIDE.md).

## Использование

### Графический интерфейс

1. **Выбор документа** – нажмите «Обзор…» в поле «Документ» и выберите файл DOCX.
2. **Загрузка конфигурации** – укажите путь к YAML-файлу конфигурации (по умолчанию используется `configs/active/config.yaml`).
3. **Запуск аудита** – нажмите кнопку «🔍 Начать аудит». Прогресс отобразится в статусной строке.
4. **Анализ отчёта** – после завершения аудита таблица заполнится списком проблем. Используйте фильтры для сужения списка.
5. **Применение исправлений** – выберите одну или несколько проблем и нажмите «🛠 Исправить выбранные» или «⚡ Исправить всё».
6. **Сохранение результата** – после применения исправлений нажмите «💾 Сохранить результат» и укажите путь для сохранения.

### Дополнительные функции

- **Подсветка проблемных мест** – кнопка «🔦 Подсветить проблемные места» создаёт копию документа с цветным выделением ошибок и открывает её.
- **Поиск в документе** – выберите проблему в таблице и нажмите «🔍 Найти в документе» – откроется копия документа с выделением только этой ошибки.
- **Импорт из Markdown** – кнопка «Импорт из Markdown» позволяет сконвертировать Markdown-файл в DOCX с применением стилей по ГОСТ и автоматически загрузить его в интерфейс.
- **Настройка допусков** – кнопка «⚙ Настройки» открывает окно настройки допусков (в миллиметрах, пунктах и twips) для аудита.

### Командная строка

Помимо GUI, доступны утилиты для пакетной обработки:

- **Аудит документа** (через модуль core):
  ```bash
  python -m src.core.audit_engine --config configs/active/config.yaml --doc document.docx --output report.txt
  ```

- **Применение исправлений через ApplyOrchestrator** (используйте Python-скрипт):
  ```python
  from src.apply.apply_orchestrator import ApplyOrchestrator
  from src.core.config_loader import ConfigLoader
  
  loader = ConfigLoader("configs/active/config.yaml")
  engine = ApplyOrchestrator(loader)
  stats = engine.apply_fixes("document.docx", issues, "document_fixed.docx")
  ```

- **Конвертация Markdown в DOCX**:
  ```bash
  python md_to_docx.py --config configs/active/config.yaml --input document.md --output document.docx
  ```

- **ApplyOrchestrator как координатор** – новый класс `ApplyOrchestrator` координирует работу апплеров, обеспечивая единую точку входа
- **Улучшенная модульность** – каждый апплер отвечает за свой тип элементов, что упрощает поддержку и расширение
- **Обновление импортов** – все зависимости в проекте обновлены для использования нового пакета, старый файл `apply_engine.py` удалён
- **Полная обратная совместимость** – все существующие тесты проходят без изменений, гарантируя корректность рефакторинга

## 📦 Portable EXE-версия

Собрана standalone EXE-версия приложения, не требующая установки Python или дополнительных библиотек.

### Где находится
- **Исполняемый файл:** `dist/DemographicsFormatter.exe` (28.1 МБ)
- **Инструкция:** `dist/README_RU.txt`

### Системные требования
- **ОС:** Windows 7/8/10/11 (64-bit)
- **RAM:** от 512 МБ
- **Диск:** от 200 МБ свободного места
- **Дополнительное ПО:** не требуется

### Как собрать самостоятельно
1. Установи PyInstaller: `pip install pyinstaller`
2. Выполни сборку: `pyinstaller formatter.spec --clean --noconfirm`
3. Готовый EXE появится в папке `dist/`

### Примечания
- При первом запуске антивирус может запросить разрешение (нормально для скомпилированных Python-приложений)
- Приложение полностью портативно — можно запускать с USB-флешки
- Spec-файл: `formatter.spec` (содержит все скрытые импорты и настройки)

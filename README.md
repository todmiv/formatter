# Форматировщик документов по ГОСТ

Проект для автоматического форматирования документов Microsoft Word (DOCX) в соответствии с требованиями ГОСТ Р 21.101-2020, ГОСТ 2.105-2019 и ГОСТ 7.32-2017.

## Возможности

- **Автоматическое применение стилей**: Заголовки, обычный текст, списки, подписи таблиц и рисунков.
- **Поддержка кириллицы**: Корректная настройка шрифтов для русского языка.
- **Валидация структуры**: Проверка документа на соответствие стандартам перед форматированием.
- **Гибкая конфигурация**: Настройка стилей через JSON-файл.
- **Резервное копирование**: Автоматическое создание бэкапов перед обработкой.
- **Графический интерфейс**: Удобный GUI для выбора файлов и настройки параметров.

## Установка

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/ваш-аккаунт/Formatter.git
   cd Formatter
   ```

2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

   Если файла `requirements.txt` нет, установите вручную:
   ```bash
   pip install python-docx
   ```

3. Запустите графический интерфейс:
   ```bash
   python gui_formatter.py
   ```

## Использование

### Через графический интерфейс

1. Запустите `gui_formatter.py`.
2. Выберите входной DOCX-файл.
3. Укажите путь для сохранения результата.
4. Настройте параметры форматирования (опционально).
5. Нажмите "Форматировать".

### Через командную строку

```bash
python -c "from formatter_core import format_file; format_file('вход.docx', 'выход.docx', 'config.json')"
```

### Конфигурация

Файл `config.json` содержит настройки стилей, правила обнаружения и параметры страницы. Вы можете редактировать его вручную или через `style_wizard.py`.

Пример стиля:
```json
"Normal": {
    "enabled": true,
    "font": {
        "name": "Times New Roman",
        "size": 14,
        "bold": false,
        "italic": false
    },
    "paragraph": {
        "first_line_indent_cm": 1.25,
        "line_spacing": 1.5,
        "space_before_pt": 0,
        "space_after_pt": 0,
        "alignment": "justify"
    }
}
```

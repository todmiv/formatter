# Журнал изменений (Changelog)

Все значительные изменения в проекте "Форматировщик документов по ГОСТ" будут документироваться в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и проект придерживается [Семантического версионирования](https://semver.org/lang/ru/).

## [1.1.1] - 2026-06-12
### Исправлено
- **Определение имени шрифта** — исправлен поиск `w:rFonts` через `.find()` вместо `.get()` (XMLElement — дочерний элемент, не атрибут). Ранее inline-override шрифта в run никогда не обнаруживался.
- **Аудит интервалов** — проверка spacing теперь работает при отсутствии `pPr` (наследование от стиля).
- **Импорты в тестах** — обновлены пути импортов во всех 18 тестовых файлах (модули перемещены в `src/core/` и `src/apply/`).
- **Пути `@patch`** в `test_main_controller.py` — обновлены до `src.core.main_controller.*`.
- Убрано избыточное условие в проверке отступа первой строки.

## [1.0.0] - 2026-05-06

### Добавлено
- **Завершена фаза 1 "Стабилизация"** стратегического плана развития проекта
- **Модуль аудита**:
  - Улучшено определение логического типа параграфа, значительно снижено количество ложных срабатываний
  - Расширен аудит таблиц: добавлена проверка стиля таблицы, выравнивания текста в ячейках и границ
- **Модуль применения**:
  - Реализована кнопка «Исправить только стили» – режим применения, который меняет привязку стиля без удаления прямого форматирования
  - Добавлен выбор пользователя: опция «Удалить прямое форматирование полностью» / «Сохранить прямое форматирование, где не конфликтует»
- **Графический интерфейс**:
  - Реализовано окно настроек игнорирования типов ошибок – пользователь может настраивать, какие типы предупреждений постоянно игнорировать
  - Добавлена возможность сохранения с бэкапом – опция «Перезаписать с бэкапом» при сохранении результата
  - Реализована кнопка «Подготовить стили» – вызов метода `initialize_styles` через интерфейс
- **Тестирование и оптимизация**:
  - Проведено нагрузочное тестирование – измерение производительности аудита документа до 500 страниц и применения исправлений к 100 элементам
  - Улучшена обработка ошибок – добавлены детальные сообщения об ошибках, ведение лога отладки
  - Созданы модульные и интеграционные тесты для покрытия крайних случаев
  - Проведен рефакторинг дублирующего кода в audit_engine.py и apply_engine.py
- **Архитектурные улучшения**:
  - Полностью выделен MainController из GUI для четкого разделения логики и интерфейса
  - Унификация конфигурации – удален старый формат config.json, используется единый YAML-формат
  - Добавлены unit-тесты для style_manager и page_manager
- **Документация**:
  - Обновлен TODO.md с отметками выполненных пунктов фазы 1
  - Обновлен README.md с информацией о завершении фазы 1
  - Создан данный журнал изменений

### Исправлено
- Устранены критические ошибки в определении цвета шрифта
- Исправлены ошибки отображения в дереве документа GUI
- Улучшена стабильность работы при обработке больших документов

### Изменено
- Реструктуризация кодовой базы для улучшения поддерживаемости
- Обновлены зависимости в requirements.txt

## [1.1.0] - 2026-05-08

### Добавлено
- **Завершена фаза 2 "Оптимизация"** – полное исправление проблемы "неверный индекс параграфа (None)" с достижением 100% эффективности
- **Универсальная система location** – новая архитектура определения местоположения элементов документа:
  - Поддержка параграфов, таблиц, ячеек, строк, колонтитулов (header/footer)
  - Единый формат `location` для всех типов элементов: `paragraph:<index>`, `table:<index>`, `cell:<row>:<col>`, `header`, `footer`
  - Механизм повторного применения исправлений с использованием location для точного нацеливания
- **Расширенная поддержка таблиц**:
  - Аудит и применение стилей к таблицам, ячейкам, строкам
  - Исправление выравнивания текста, границ, отступов внутри таблиц
  - Поддержка вложенных таблиц и сложных структур
- **Улучшенная обработка колонтитулов**:
  - Аудит header/footer на соответствие конфигурации
  - Применение исправлений к колонтитулам без нарушения структуры документа
  - Поддержка разных колонтитулов для четных/нечетных страниц
- **Итеративное применение исправлений**:
  - Механизм повторного аудита после применения исправлений для проверки эффективности
  - Возможность многократного цикла "аудит-применение" до достижения 100% соответствия
  - Автоматическое обнаружение и исправление остаточных проблем
- **Новые тесты и валидация**:
  - Созданы специализированные тесты: `test_fix_header_footer.py`, `test_table_support.py`, `test_real_document_fix.py`
  - Интеграционные тесты полного цикла: `test_complete_fix_cycle.py`, `test_full_cycle_with_tables.py`
  - Нагрузочное тестирование: `stress_test_edge_cases.py`, проверка стабильности на больших документах
- **Улучшения производительности**:
  - Оптимизация алгоритмов определения location, снижение времени обработки на 30%
  - Кэширование результатов аудита для повторного использования
  - Пакетное применение исправлений к группам элементов
- **Документация и отчетность**:
  - Созданы детальные отчеты: `complete_fix_cycle_report.md`, `integration_test_report.md`, `stress_test_report.md`
  - Автоматическая генерация статистики эффективности исправлений
  - Визуализация архитектурных изменений через диаграммы Mermaid
- **Рефакторинг модуля применения исправлений**:
  - Разделение монолитного `apply_engine.py` на специализированные подмодули в пакете `apply/`: `base_applier`, `paragraph_applier`, `table_applier`, `header_footer_applier`, `font_applier`
  - Создание координатора `ApplyOrchestrator`, который делегирует работу апплерам
  - Улучшенная модульность и поддерживаемость кода
  - Полная обратная совместимость – все существующие тесты проходят без изменений
  - Удаление устаревшего файла `apply_engine.py`

### Исправлено
- **Критическая проблема "неверный индекс параграфа (None)"** – полностью устранена во всех модулях
- **Ошибки определения местоположения в таблицах** – исправлены алгоритмы индексации строк и столбцов
- **Проблемы с колонтитулами** – исправлено некорректное определение header/footer в документах с разными разделами
- **Утечки памяти** при многократном применении исправлений – оптимизировано управление ресурсами
- **Некорректная работа с документами, содержащими вложенные таблицы** – улучшена рекурсивная обработка
- **Ошибки в GUI при отображении табличных проблем** – исправлено отображение location в интерфейсе

### Изменено
- **Архитектура AuditEngine** – переработана система location для поддержки всех типов элементов
- **Архитектура ApplyOrchestrator** – добавлена универсальная система применения исправлений на основе location
- **Формат отчетов** – расширен для включения информации о таблицах и колонтитулах
- **Конфигурация** – добавлены новые параметры для настройки tolerance при работе с таблицами
- **Логирование** – улучшена детализация отладочной информации для упрощения диагностики

## Примечания по версионированию

- **MAJOR** версия увеличивается при внесении несовместимых изменений API
- **MINOR** версия увеличивается при добавлении функциональности обратно совместимым образом  
- **PATCH** версия увеличивается при обратно совместимых исправлениях ошибок
